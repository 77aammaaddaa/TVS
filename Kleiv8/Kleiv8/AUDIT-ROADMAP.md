# Kleiv8 — Audit + Roadmap (from Drive + Docs)
## Brand
- KLEIV / Kleiv8 — السويس، خلف نقابة المهندسين — Soft Opening Sep 2026 — +20 10 23328432 — @kleiv.eg (FB/IG/TikTok)
- Palette: #213A23 deep forest, #2C795D emerald, #FCFCFC off-white. Fonts: Arial Nova Light (wordmark) + Arial Rounded MT Bold (slogan). Infinity ∞ = 8 + continuity.
- Doodles: croissant guy, balance girl, barista girl, ice cubes, cup, infinity, waves.

## Menu — 82 items (Kleiv8 db menu 2026-11-07)
- Ice Coffee 10, Hot Coffee 12, Frappe & Shake 10, Fresh Juice 3, Mix Soda 5, Matcha 9, Non Coffee 6, Extra 6, Soft Drink 2, Bakery 8, Bagels 6, Dessert 5
- Avg 127 EGP, Range 15-190. Heroes: Ice Spanish Latte 140, Ice Latte 120, Pistachio Ice Latte 170, Milky Pistachio Matcha 190, Croissant 100-140.

## Tech (from Drive research)
- Cloudflare Pages (unlimited bandwidth, Egypt edge) > Vercel (100GB cap)
- Google Sheets as DB + Cloudflare Cache (0.05s read, edit from mobile)
- Vite + Vanilla JS (Kaei style) — no heavy framework — Web Audio API for sounds, localStorage for gamification
- Current repo: github.com/77aammaaddaa/TVS/tree/main/Kleiv8 — not fetchable via browser here (private / cache miss) — audit based on Drive docs + live spec kleiv8.pages.dev

## Gaps
1. Handle split @kleiv.eg vs @kleiv8.eg → unify to @kleiv.eg
2. No Google Business Profile strong result
3. No unified digital menu / Linktree
4. No Storytelling in Arabic
5. No Speed Mode for cashier queue
6. No loyalty / Wallet pass
7. No Live Vibe Meter
8. No Secret Vault

## Roadmap — 3 Phases
Phase 1 (launch): Intro 1.4s + Speed/Vibe toggle + Infinite Loop Canvas + Menu from Sheets + WhatsApp order + Secret Vault (8 taps on ∞)
Phase 2 (30d): WebAR Cup (MindAR) + Avatar Doodle Generator + Wallet Pass (Apple/Google) + Live Vibe Meter
Phase 3 (60d): Jukebox (Spotify) + Pay It Forward (gift coffee) + UGC wall
